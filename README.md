# Eksamen i TK1104 Digital Teknologi

> Eksamensperiode: 17.12.2024 (3 timer eksamen)
>
> Eksamensform: Multiple Choice individuell eksamen
>
> Karakter: 86 / 90 **Bestått**

## Om emnet
Digital teknologi (TK1104) ved Høyskolen Kristiania (1. semester). Emnet ga en innføring i datamaskinens oppbygning, digital representasjon av informasjon, operativsystemer og nettverkskommunikasjon. Vi lærte hvordan maskinvare og programvare samspiller for å lagre, behandle og overføre data.

Les mer om emnet ved Høyskolen Kristiania [**her**](https://www.kristiania.no/studieportal/fakultet-for-helse-og-teknologi/bachelorniva/tk1104/digital-teknologi/) <img src="https://www.kristiania.no/dist/assets/images/favicon-32x32.png?v=2" width="16" height="16" alt="Kristiania">
